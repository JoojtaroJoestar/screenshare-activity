Política de Privacidade

Última atualização: agosto de 2026

1. Informações que Coletamos

Ao usar o ScreenShare através do Discord, coletamos temporariamente as seguintes informações:

  • Nome de usuário do Discord — para identificá-lo nas transmissões
  • ID do usuário Discord — para autenticação via OAuth2
  • Avatar do Discord — exibido na interface
  • ID do canal de voz — para filtrar transmissões do seu canal atual

2. Como Usamos as Informações

As informações coletadas são utilizadas exclusivamente para:

  • Exibir seu nome e avatar durante as transmissões
  • Identificar qual canal de voz você está usando
  • Gerenciar conexões WebRTC de baixa latência

3. Armazenamento de Dados

O ScreenShare não armazena permanentemente nenhum dado pessoal. Todas as informações são mantidas apenas em memória durante sua sessão ativa e descartadas quando você desconecta.

4. Compartilhamento de Dados

Não compartilhamos, vendemos ou transferimos suas informações pessoais para terceiros.

5. Dados de Vídeo e Áudio

O conteúdo das transmissões de tela é transmitido diretamente entre os participantes via WebRTC (peer-to-peer). O servidor intermediário não grava nem armazena nenhum conteúdo de vídeo ou áudio.

6. Segurança

Utilizamos conexões WebRTC criptografadas e, quando disponível, HTTPS para proteger as comunicações.

7. Seus Direitos

Como não armazenamos dados pessoais de forma permanente, sua desconexão do Serviço resulta automaticamente na remoção de todas as suas informações do sistema.

8. Contato

Para dúvidas sobre esta Política de Privacidade, entre em contato pelo Discord.
